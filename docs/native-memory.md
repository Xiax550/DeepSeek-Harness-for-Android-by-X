# DHA 记忆

DHA 的 Android 集成模块自带长期记忆，不需要安装第三方记忆插件。数据位于应用私有沙箱的 `/root/.dsh/dha-memory/memory.db`，升级保留，卸载应用会删除。数据不额外上传到记忆服务；开启自动回忆后，相关条目会作为对话上下文发送给用户选定的模型提供商。

## 能力

- 分类：用户偏好、项目、事实、经验、话题、规则与自身描述。
- 中文关键词检索和按工作区隔离。全局条目使用 `*` 工作区。
- 编辑记忆可修改作用域为全局或指定工作区绝对路径；所属项目仅用于分类，不决定作用域。列表的工作区下拉框仅用于筛选。迁移作用域保留条目编号、来源和原始导入字段。
- 自动注入相关记忆及稳定偏好，最多 4500 字符；不改写原始用户消息或图片附件。
- 设置分为「记忆、回忆、遗忘」。模型工具 `dha_memory_remember/search/update/forget`；记忆页提供开关、搜索、分页、编辑、删除和 JSON 导出。
- 「记忆」的对话引用与结束后保存分别控制。每轮结束后延迟 5 秒、合并同一会话请求，用默认模型最多额外调用一次补存稳定信息；与回忆共享断点和串行执行器，不整理其他会话、不触发精简或清理。默认启用，可关闭；可能产生额外模型费用。失败或超出单次文本预算的部分由回忆补记，不阻塞结果输出。
- 正常对话按需引用记忆；可选的定时「回忆」默认关闭，单独启用后会调用默认模型整理全部工作区的对话，不唤醒屏幕。
- 记忆是可能过时的参考，不是系统指令或执行授权。不应保存密码、验证码与令牌。

## 旧数据迁移

参考喵记忆的分类与跨会话设计，使用 DHA 自己的存储、检索和会话集成代码。喵记忆的 MIT 许可与原始代码归属保持不变。

首次升级按工作区索引与常用工作目录发现 `.dsh-meow/memory.db`，以只读事务检查并导入七类条目；原始字段完整保存在 `extra` 中。源数据库、日志和插件安装文件均不删除。导入失败保留原加载配置；导入成功后停用喵记忆加载项，避免重复注入，配置原件以 `.before-dha-memory` 后缀保留。其他插件和依赖版本不变。后续遇到的工作区也会按需导入，每个源库只导入一次，删除的条目不会因重启重新出现。

自定义记忆目录、后台 dream 整理历史与逐会话读写开关不转换成 DHA 配置；源文件仍在备份中。重新启用旧插件前应关闭内置记忆，避免两套系统同时参与对话。

## 回忆

- 设置的「记忆管理 / 回忆」页签分别提供检索、折叠预览、编辑、归档记忆恢复，以及定时整理。对话中自动引用记忆和定时回忆是不同开关。
- 默认回忆时间段为 23:00 至次日 06:00，采用手机设置页的时区。开始、结束分别设置，结束早于开始代表跨午夜，两者不能相同。旧的单点时间保留为开始时间，未设置结束时间时默认为开始后 7 小时。首次启用会补记所有工作区尚未整理的会话，不局限当前工作区或当天；之后按会话编号、事件序号和字符偏移增量补记。过长消息分批处理，不静默截断。
- 单次最多 42 次模型调用、8 分钟；剩余内容显示「待继续」，下次回忆继续，也可手动继续。网络或模型错误不推进失败批次的断点；失败自动重试间隔至少 30 分钟。
- 模型只接收正式用户文字和助手结果，不发送图片、工具输出、思考块或插件注入；仅整理确认的稳定信息，不执行历史对话中的指令。默认模型服务可能产生费用，首次开启需确认。
- 精简在同一工作区、分类和项目内部合并语义重复条目；原条目转为已归档，不永久删除。模型合并编号和文本通过校验后才事务写入，期间发生人工编辑的条目不覆盖。首次合并前保存完整 JSON 备份。
- 「清理多余会话」独立开关默认关闭，默认至少保留 7 天。仅归档空会话和同一工作区内容（含附件）完全相同的旧会话，较新副本保留。独有内容、置顶、子代理、正在执行和整理中新增消息的会话不清理。归档前保存原事件 JSON，不强制停止活动，可在「归档会话」恢复。
- 整理状态、开关与断点持久化到记忆库；自动备份在 `/root/.dsh/dha-memory/review-backups`。应用服务运行时每分钟轻量检查，仅在允许时间段内自动回忆，每个时间段最多成功一轮。安卓冻结/结束服务时不能保证准点，恢复时仍在时间段内才补做，否则等下一个时间段。自动整理到结束时间会中止未完成批次并保留已成功批次；手动「立即回忆 / 继续回忆」不受时间段限制。关闭记忆、定时回忆或修改时间段会取消当前整理，已成功批次保留。

## 遗忘

- 独立于模型回忆的定时文件清理，默认关闭，启用前确认永久删除风险；关闭「启用记忆」总开关也会暂停遗忘。默认每天 03:00 检查，每小时轻量检查调度；后台被冻结可能延后。覆盖全部工作区。
- 清理范围默认「仅自动化会话」：识别 `schedule` 消息来源；兼容旧刷 B 站插件的专属工作区 `/root/.dsh/bili-duty` 加固定首条任务提示，且不允许后续人工消息。未知来源、普通聊天及人工追问默认保护，绝不只按标题或目录删除。其他插件无明确来源时暂不自动识别。
- 可显式切换「全部闲置会话」，扩大范围前确认。缩小范围会保护原待删除的普通会话；若文件此前已移入删除暂存区但删除失败，则保留这些待处理文件，只有再次允许对应范围才继续清理，不擅自扩大授权。
- 默认闲置满 3 天先归档，从本功能实际归档的时刻再保留 2 天后永久删除，不按会话创建时间直接跳过宽限期。归档期间可在归档会话中恢复；恢复会取消本轮删除计时并重新给予闲置宽限。
- 默认保护未完整回忆的会话，可显式关闭此保护。执行中、置顶、包含附件、有父子关系和手动归档的会话不永久删除；仍加载的会话暂缓到卸载或重启服务后处理。每次最多处理 40 个，不调用模型。
- 删除前再次核对全部事件与状态，取得持久层独占写锁，仅处理经过校验的会话目录，移至私有暂存区后删除，不在手机保留同体积副本。异常中断后重试已登记的暂存文件。保存的长期记忆不随原会话删除。
- 归档本身不减少磁盘占用，永久删除会话日志和该会话目录才释放存储空间。精简记忆主要减少有效条目与模型上下文，历史记忆副本仍保留以便恢复。

## 验证

`node --test plugin/dsh-plugin-android/test/memory.test.mjs`

`node --test plugin/dsh-plugin-android/test/memory-review.test.mjs`

`node --test plugin/dsh-plugin-android/test/memory-forget.test.mjs`

`node scripts/verify_meow_backup.mjs <解压后的备份目录>`

备份脚本在手机沙箱中使用 SQLite 在线备份 API，包含已提交的 WAL 内容，生成完整性检查结果、逐表计数与逐文件 SHA256。电脑备份目录应视为私人数据，不要提交到源码仓库或公开发布。
